# 校验清单

> **什么时候读这一篇**：**阶段 9 校验闸门** 时逐条对照执行；**阶段 10 交付前**再整份过一遍。开工前扫一眼第 4 节的交付清单也有用。

一句话原则：**AI 看不到画面、听不到声音，所以每一项都必须落到命令或人眼打勾上。** 闸门不许跳步，`check_assets.py` 与 `check_video.py` 必须 **0 ERROR**。

## A. 自动闸门

### A0 · 环境体检（阶段 0 与阶段 3 各跑一次）

```bash
python scripts/doctor.py
```

| 项 | 通过条件 | 常见失败原因 | 不通过怎么办 |
| --- | --- | --- | --- |
| 依赖完整性 | 无 `MISSING`（`WARN` 可接受，但要逐条说明） | 没装 ffmpeg/ffprobe；Python <3.9；Node <18；`pip install -r requirements.txt` 没执行；Playwright 浏览器没下载 | 按脚本打印的安装命令逐条装，装完**重跑一次**到没有 `MISSING` 再开工。**没有 ffmpeg 不要往下走** |

### A1 · 渲染前素材闸门

```bash
python scripts/check_assets.py
python scripts/check_assets.py --strict     # 需要更严时用（WARN 也当失败）
```

| 项 | 通过条件 | 常见失败原因 | 不通过怎么办 |
| --- | --- | --- | --- |
| 缺文件 | 0 ERROR | `timing.json` 里引用的图/音频/字体路径拼错；素材在别的目录 | 按报错路径逐个补齐；路径一律用相对 `public/` 的写法 |
| 图片宽度 | **图片宽度 ≥ 显示宽度 × 2** | 用了 AI 工具自带浏览器的 1 倍截图；`capture.py` 忘了 `--factor 2`；后期被 `prepare` 限宽压过头 | 重新截图（`--factor 2`）或换更宽的源图；1080 宽显示需要 **2160 像素**，别用放大算法硬拉 |
| 字体缺字 | 文案里的每个字都能在字体里找到 | 用了像素字体/手写字体排中文；emoji 不在字体覆盖范围 | 中文 fallback 回黑体栈（见 `template/fonts.json` 的 `stack`）；emoji 换成图标或删掉 |
| 混音文件 | `public/<music.file>`（模板是 `public/audio/music.wav`）存在 | 忘了跑 `python scripts/mix.py` | 先跑 `tts.py all` → `mix.py`，再重跑本闸门 |

### A2 · 配音时长闸门

```bash
python scripts/tts.py audit
```

| 项 | 通过条件 | 常见失败原因 | 不通过怎么办 |
| --- | --- | --- | --- |
| 时长 | 无 `TOO_LONG` | 稿子字数超窗口；语速写太慢 | **回去删字改稿**（见 `references/配音与字幕.md` 第 4 节），最多加速 **12%**，禁止硬压 |
| 缺句 | 无 `MISSING` | `timing.json` 加了新 `line` 没重新生成 | `python scripts/tts.py all` 或 `tts.py one <id>` |
| 尾部拖音 | 无未确认的 `ECHO` | 句尾虚词拖长音 | **人工听一遍**再决定切静音还是换句尾用词；确认过的要在 `需求确认.md` 留一句说明 |

### A3 · 抽帧联系表（阶段 9 的视觉入口）

```bash
npm run stills -- --scenes                 # 每场景抽 40% 与 80% 两帧
python scripts/media.py sheet out/stills --cols 4
```

两帧的含义要清楚：**40% 处**看"元素是否出齐"，**80% 处**看"出齐后是否留够停留"（出齐后停留 ≥0.6 秒）。
联系表出来后**必须逐张看过**，按下节 B 的审图项打勾，不许只看文件名。

### A4 · 成片闸门

```bash
python scripts/check_video.py out/final-1080p.mp4 --expect 1080x1920 --log out/render.log
```

| 项 | 通过条件 | 常见失败原因 | 不通过怎么办 |
| --- | --- | --- | --- |
| 规格 | 分辨率/帧率/时长与 `timing.json` 一致（**±0.2 秒**） | 改过 `duration` 没重渲；场景表首尾不相接导致总长对不上；`fps` 与渲染命令不一致 | 核 `timing.json` 的 `duration` 必须等于最后一个场景的 `end`，改完重渲 |
| 音轨 | 有音轨且不是静音 | `mix.wav` 没生成；渲染时音频路径写错 | 跑 `mix.py` 后确认 `public/audio/music.wav`（即 `timing.json` 的 `music.file`）存在，再重渲 |
| 响度 | **-16 ~ -12 LUFS**（母带目标 **-14 LUFS**、真峰值 **-1 dBFS**） | 混音没做母带；音乐层压得太狠；音效叠加过冲 | 重跑 `python scripts/mix.py`，再用 `python scripts/mix.py --env` 看包络定位是哪一段超标 |
| 空档 | 无 **≥1.0 秒**的空档（转场瞬间除外） | 音乐剪接处断了；某句旁白与下一句之间留白过长；场景窗口之间有空隙 | 查 `music.segments` 的剪接点；补铺底音；核 `scenes` 是否首尾相接 |
| 渲染日志 | 无 `cannot be decoded` / `Error:` / `failed to load` | 字体没打包进渲染进程；图片路径用了本地绝对路径；音频编码不受支持 | **即使渲染"成功结束"也按失败处理**：按日志里的文件名逐个修，修完重渲 |

### A5 · 混音包络复核

```bash
python scripts/mix.py --env
```

看两件事：**每句人声是否比该处音乐高 ≥6 dB**（脚本里的 `vo_margin`），以及片头 0.3 秒淡入、片尾 0.6 秒淡出有没有生效。某一句话期间音乐明显高过其他段，说明 ducking 没覆盖到那一句——把该句的 `at` 与场景窗口对齐后重跑 `mix.py`。

### A6 · 字体与字幕

- `python scripts/fonts.py check` 必须 0 缺字；改了文案、加了场景后要重跑 `subset`。
- 导出 SRT / ASS 后**抽一帧对时**（`subtitles.py burn --preview 8` 自动抽帧）：字幕在画面底部、落在下 18% 安全区之上、
  时间和人声对得上（早于人声读完就消失 = 不合格）。
- 硬字幕流程固定为「`npm run render:1080:nosubs` → `subtitles.py burn`」；烧完的片子要再过一遍 `check_video.py`。

### A7 · 交付预检与封面

- `python scripts/deliver.py check out/final-1080p.mp4 --platform all`：目标平台必须 0 ERROR；
  码率/体积类 WARN 要逐条说明（抖音、小红书的官方口径脚本抓不到，按「需人工确认」处理）。
- 封面 `python scripts/deliver.py cover out/final-1080p.mp4 --title "..."`：三张候选 + 联系表，**必须逐张看图**。

## B. 抽帧审图 checklist（人眼，逐张打勾）

每张抽帧都要过一遍下面七项，**任何一项不过都算不通过**。

| # | 审图项 | 通过标准 | 不通过怎么办 |
| --- | --- | --- | --- |
| B1 | **安全区** | 竖屏安全区 **上 10% / 下 18% / 左 6% / 右 14%**：所有文字、Logo、关键图形完整落在安全区内 | 把元素移进安全区，或缩小整体版式；右侧 14% 是平台互动按钮的位置，那里永远不放内容 |
| B2 | **截图清晰度** | 界面里最小的正文也读得清（按 1080 宽算 ≥24 px）；放大推近后不发虚 | 重新截图并 `--factor 2`（1080 宽显示 → 2160 像素）；或减少推近幅度 |
| B3 | **文字可读性** | 字幕单行 **≤13 字**、**≤2 行**、距底 **18%**；与背景对比足够（深底浅字/浅底深字） | 先删字再改排版；给字幕加轻微底衬或描边 |
| B4 | **品牌名拼写** | 品牌中文名、英文名、网址拼写与官网**逐字符一致**（含大小写与域名后缀） | 直接从官网复制，不要手打；网址停留 **≥2.5 秒**且在全片能量最高处 |
| B5 | **空画面** | 没有全空、全黑、只剩背景的帧；每帧都有信息 | 缩短空档或补一层包装图形；核该场景窗口是否比内容长 |
| B6 | **色差** | 全片配色只来自 `brand.colors` 的 `bg/fg/accent` 与黑白色阶；同一颜色在不同帧里一致 | 统一用 `timing.json` 的颜色变量，禁止组件内写死 hex |
| B7 | **遮挡** | 字幕不被图形/手机壳/截图边缘压住；屏上大字**最多比旁白早 1.5 秒**、停留 **≥ 字数/6 + 0.35 秒**（活到人声读完） | 调 `at` 时间与 `captions.bottom`；重新核每句的停留时长 |
| B8 | **字幕只有一层** | 烧了硬字幕的片子：字只有一层（没有和画面自带的字叠在一起）、单行 ≤13 字、落在下 18% 安全区之上 | 先 `npm run render:1080:nosubs` 再烧；或调 `captions.bottom` / 改文案 |
| B9 | **封面** | 三张候选封面逐张看过：标题在安全区内、不压住画面自带的字、不折成 3 行以上、品牌名与网址拼写正确 | `deliver.py cover --position top/middle/bottom`、换抽帧时刻、或改短标题 |

审图时顺手核三条节奏底线（肉眼能判断）：开场 **≤2.0 秒**出钩子、重点镜头 **≥1.2 秒**、快切 **≥0.5 秒**；同一版式**最多连用 2 次**。

## C. 交付前检查

| # | 检查项 | 通过条件 | 不通过怎么办 |
| --- | --- | --- | --- |
| C1 | 规格 | 成片为 **1080×1920**、时长 30~60 秒（默认 45 秒 ±10）、有音轨 | 核 `timing.json` 后重渲；横版是**可选**交付，不是替代 |
| C2 | 响度 | 母带 **-14 LUFS / 真峰值 -1 dBFS**，`check_video.py` 落在 -16~-12 LUFS | 重跑 `mix.py`；不要用播放器的"音量归一化"掩盖问题 |
| C3 | 时长 | `duration` 等于最后一个场景的 `end`，与成片实测差 **≤0.2 秒** | 改 `timing.json` 的场景表后重渲，不要只改 `duration` |
| C4 | 网页版播放 | `npm run web:build && npm run web:serve` 能打开、能播放、有声音 | 检查 `out/web` 是否生成、音频文件是否被构建忽略；路径必须相对 `public/` |
| C5 | 文件名与目录结构 | 成片 `out/final-1080p.mp4`；抽帧在 `out/stills/`；联系表 `out/check-*.jpg`；工程根目录有 `需求确认.md`、`调研笔记.md`、`src/timing.json` | 缺哪个补哪个；**`node_modules/`、`out/`、`public/fonts/` 下的字体子集都不进版本库**（见 `.gitignore`） |
| C6 | 文档齐全 | `需求确认.md` 有全部决定 + 每一轮修改意见**原话**；`调研笔记.md` 有事实/素材/音乐/字体四张表 | 补记；改版意见只写"已改"不算，必须留原话 |
| C7 | 交付话术 | 告诉用户三件事：成片路径、网页版地址、"哪里还可以改 + 改一处要重做哪些步骤" | 按 AGENTS.md 阶段 11 的影响范围表回答 |
| C8 | 字幕产物 | 需要字幕时：`out/subtitles/zh.srt`（+ 可选 `zh.ass`）已生成并与成片对时；要硬字幕的话成片里只有一层字 | 重跑 `subtitles.py srt/ass`；硬字幕走 nosubs → burn 流程 |
| C9 | 封面与平台规格 | 封面三张候选已出且逐张看过；`deliver.py check` 在目标平台 0 ERROR（WARN 已逐条说明） | `deliver.py cover` / `deliver.py check --platform <目标>`；码率不足就降 CRF 重渲 |

## D. 一页速查（打印版）

```bash
python scripts/doctor.py                                    # 无 MISSING
python scripts/check_assets.py                              # 0 ERROR
python scripts/tts.py audit                                 # 无 TOO_LONG / MISSING
npm run stills -- --scenes                                  # 40% 与 80% 两帧
python scripts/media.py sheet out/stills --cols 4           # 联系表逐张看过
python scripts/mix.py --env                                 # 人声高 ≥6 dB
npm run render:1080
python scripts/check_video.py out/final-1080p.mp4 --log out/render.log   # 0 ERROR
npm run web:build && npm run web:serve                      # 网页版可播
```

**通过判据一句话**：`doctor.py` 无 MISSING · `check_assets.py` 与 `check_video.py` **0 ERROR**（WARN 逐条说明）· `tts.py audit` 无 `TOO_LONG`/`MISSING`（`ECHO` 人工确认）· 联系表逐张打完 B1~B7 的勾 · C1~C7 全过。
